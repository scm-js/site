집계 환경 설정 ▸ 일반 ▸ 개인정보에서 집계를 켜 둔 사람들의 숫자입니다. 데스크톱 앱과 다른 곳에서 호스팅한 에디터는 아무것도 보내지 않습니다. 같은 날 서로 다른 세 사람 이상, 모두 합쳐 열 명 이상이 보낸 값만 보여 줍니다. 하루의 방문을 다음 날의 방문과 이어 주는 것이 없어서, 다른 날 다시 온 사람은 다시 셉니다. 오늘의 숫자는 보여 주지 않으며, 모든 숫자는 반올림합니다. 무엇을 집계하는지는 개인정보 처리방침 (영문)에 있습니다.
GitHub 릴리스 플러그인 API (영문) 버그 신고 MIT 라이선스. 블리자드 엔터테인먼트와 관련이 없으며 블리자드의 보증을 받지 않았습니다. 통계 개인정보 처리방침 (영문) 방문 통계는 쿠키 없이 Cloudflare Web Analytics로 집계합니다.
